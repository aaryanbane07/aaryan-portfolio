# Aaryan Bane — Portfolio

A responsive React + Vite portfolio website.

## Run locally on Mac

1. Install Node.js (LTS) if it is not already installed: https://nodejs.org/
2. Unzip this folder.
3. Open Terminal and move into the project folder:
   ```bash
   cd ~/Downloads/aaryan-portfolio
   ```
   (Adjust the path if you extracted it somewhere else.)
4. Install dependencies:
   ```bash
   npm install
   ```
5. Start the local development server:
   ```bash
   npm run dev
   ```
6. Open the local URL shown in Terminal (usually http://localhost:5173).

## Build for deployment

```bash
npm run build
```

Vite creates the production website in the `dist` folder.

## Deploy to Vercel

1. Push this project folder to a new GitHub repository.
2. Sign in to https://vercel.com/ using GitHub.
3. Import the repository.
4. Keep the default Vite settings:
   - Build command: `npm run build`
   - Output directory: `dist`
5. Click Deploy.
